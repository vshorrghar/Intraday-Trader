## 12. BROKER API (Dhan)

- **API**: Dhan REST API v2 (https://api.dhan.co/v2)
- **Auth**: TOTP-based headless (pyotp generates code, POST to /app/generateAccessToken)
- **Token expiry**: ~24 hours (session file reuses same-day token)
- **Orders**: POST /v2/orders
- **Positions**: GET /v2/positions
- **Margins**: GET /v2/fundlimit
- **Known issues**:
  - Token valid for 30 seconds during generation (must use immediately)
  - `availabelBalance` (typo in their API response — note the spelling)
  - F&O needs `exchangeSegment: "NSE_FNO"`
  - Intraday needs `productType: "INTRADAY"`, `exchangeSegment: "NSE_EQ"`
