## SECTION 8: CRITICAL HONEST ASSESSMENT

### 8.1 Is the dashboard currently useful for daily trading review?

**Partially, but only via S3/CloudFront — not locally.**

When served from S3 (where EC2 syncs data), the V1 dashboard can show:
- Today's intraday trades per profile (if `intraday_latest.json` is fresh)
- Historical P&L chart (if `history.json` exists)
- War Room top performers (frozen at May 14)

But it CANNOT show:
- Accurate F&O P&L (no per-profile fno_latest.json)
- Real-time balance (no dhan_live.json in V1)
- Swing positions (stale since May 4)
- Any V2 audit/narrative data

**Verdict: Marginally useful for intraday-only review. Not useful for multi-module overview.**

### 8.2 Can a user open ONE URL and see complete state of all 4 profiles across all 3 modules?

**No.**

- V1 shows one profile at a time (must click each)
- F&O data is missing/stale
- Swing data is 23 days old
- Positional is empty placeholder
- No single view combines all profiles

### 8.3 Can a user trust the numbers shown?

**No — with documented reasons:**

- DB P&L was proven 7-17x off from Dhan reality (May 18-19 indent bug)
- The indent bug is now fixed (commit a2e5d66), but dashboard still reads from DB
- No reconciliation layer between DB numbers and broker truth
- F&O P&L was historically synthetic (Bug T, now fixed but unvalidated on dashboard)
- Swing positions show `unrealized_pnl: 0` for all (current_price = entry_price)

### 8.4 What's the minimum work needed to make it actually useful?

1. **Ensure `intraday_latest.json` is generated per-profile on every cron run** (already coded, just needs sync working)
2. **Wire `fno_latest.json` generation** per profile (fno/dashboard.py exists but may not be called)
3. **Add `dhan_live.json` to V1** for real balance display
4. **Update `top_performers.json`** daily (fix capture cron or sync)
5. **Remove `latest.json`** (Wealth Builder Pro leftover)
6. **Pick ONE dashboard** (V1 or V2) and deprecate the other

Estimated effort: 1-2 days of EC2 work.

### 8.5 What's the work needed to make it institutional quality?

1. Everything in 8.4 above
2. **Server-side auth** (not client-side SHA-256)
3. **Dhan reconciliation** displayed on dashboard (DB vs broker truth)
4. **Real-time WebSocket** for live P&L during market hours
5. **Unified V2 dashboard** with all modules in one SPA
6. **Automated data freshness alerts** (if JSON > 1 hour old, show warning)
7. **Mobile-first redesign** (current is responsive but not mobile-optimized)
8. **Historical backfill** (populate V2 daily_pnl for all past trading days)

Estimated effort: 2-3 weeks.
