Part A: Dhan Account (Day 1)

01

Dhan App Download करो

Play Store या App Store खोलो। Search करो: Dhan
Official app: Raise Financial Services। Free download।

02

Register करो

App खोलो → 'Open Free Account'
Mobile number डालो। OTP enter करो।
(OTP = वही 6 digit code जो SMS पर आता है)

03

KYC Complete करो

KYC = Know Your Customer (सभी brokers के लिए mandatory है)

चाहिए:
📄 Aadhar card
📄 PAN card
🏦 Bank account details
📸 Selfie (app automatically लेगा)

Time: 10-15 minutes
Approval: 1-2 working days

04

₹10,000 Add करो

App में: Funds → Add Funds
UPI से transfer करो। (UPI = GPay, PhonePe, Paytm — same है)
Instant transfer होता है।

Minimum: ₹10,000
यह आपका trading capital है।

Part B: API Setup (Day 2)

05

API Access Enable करो

Dhan app में:
Bottom menu → More → API Access
'Subscribe' पर click करो।

Note: Dhan ₹499/year charge करता है। यह Dhan को जाता है, हमें नहीं।

06

Credentials Copy करो

API enable होने के बाद आपको मिलेगा:

Client ID: एक number जैसे 1234567890
Access Token: letters और numbers की लंबी string

दोनों screenshot करो। Safe रखो — ATM PIN जैसा treat करो।

07

TOTP Setup करो 🔐

TOTP क्या है? Easy explanation:

जब आप Dhan app में login करते हो — वो 6 digit OTP जो आता है — वैसा ही है TOTP।

फर्क सिर्फ यह है: हमारा system automatically generate करता है। आपको कुछ manually enter नहीं करना।

Setup:
Dhan app → Settings → Security → Enable TOTP

एक QR code और एक Secret Key दिखेगी।
Secret Key ऐसी दिखती है:
JBSWY3DPEHPK3PXP

Secret Key screenshot करो। यह हमें share करनी है।

⚠️ यह key खोई तो Dhan में reset करना होगा। Backup रखो।

Part C: Share Details

08

हमें Details भेजो

WhatsApp पर यह भेजो:

1️⃣ Client ID
2️⃣ Access Token
3️⃣ TOTP Secret Key
4️⃣ Dhan login PIN (4 digit PIN जो आपने set किया था)

हम 24 घंटे में आपका profile system में add कर देंगे। Confirm होने पर WhatsApp करेंगे।
