आपकी Safety

हर rule hardcoded है। कोई override नहीं।

Maximum Daily Loss Limit

₹600

यह system में hardcode है। कोई इंसान इसे change नहीं कर सकता।
अगर trade में ₹600 loss हो — system automatically exit करता है। उस दिन के लिए बंद।

₹10,000 account पर = maximum 6% daily loss
99% दिन यह trigger नहीं होता।

Stop Loss कैसे काम करता है

Stop Loss एक automatic emergency brake है। Example: System ने Stock X ₹200 पर खरीदा। Stop Loss automatically ₹196 पर set हुई। (2% नीचे — VIX के हिसाब से) अगर stock ₹196 पर आया → Dhan automatically sell करता है। Loss = ₹4 × shares = protected। यह order Dhan के server पर है। Internet बंद हो। हमारा server बंद हो। Stop Loss काम करेगी। हमेशा।

आपका पैसा हमेशा आपके Dhan account में

  • ✓ हम आपका पैसा hold नहीं करते
  • ✓ हम transfer नहीं कर सकते
  • ✓ हम withdraw नहीं कर सकते
  • ✓ System सिर्फ BUY/SELL orders place करता है
  • ✓ आप कभी भी अपना पैसा निकाल सकते हो
  • ✓ Dhan SEBI registered broker है

What Can Go Wrong

⚠️ Gap Down Opening

Stock अचानक बहुत नीचे open हो सकता है। Rare case में loss ₹600 से ज़्यादा हो सकता है। यह market का risk है।

⚠️ Server Downtime

हमारा server बंद हो तो new trade नहीं होगा। लेकिन existing Stop Loss Dhan पर safe है।

⚠️ High VIX Days

VIX > 18 पर system extra cautious होता है। कभी कभी पूरा दिन skip करता है। यह protection है।

⚠️ AI Errors

AI कभी कभी गलत stock चुन सकती है। इसके लिए Stop Loss है। Maximum loss हमेशा limited रहता है।
